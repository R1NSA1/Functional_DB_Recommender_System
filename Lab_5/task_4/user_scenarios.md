# Пользовательские сценарии рекомендательной системы

## 1. НОВИЧОК (Новый пользователь)

### Характеристики:
- Только зарегистрировался в системе
- Нет истории просмотров и оценок
- Не заполнил профиль

### Потребности:
- Получить базовые рекомендации
- Понять, как работает система
- Быстро найти интересные фильмы

### Ожидания:
- 5-10 рекомендаций сразу после регистрации
- Простой и понятный интерфейс
- Возможность оценить推荐的 фильмы

### Решение системы:
- Использование популярных фильмов
- Опрос при регистрации (любимые жанры)
- Контентная фильтрация на основе ответов

---

## 2. ОПЫТНЫЙ ПОЛЬЗОВАТЕЛЬ

### Характеристики:
- 20-50 оцененных фильмов
- Есть история просмотров
- Заполнен профиль

### Потребности:
- Персонализированные рекомендации
- Учет предыдущих оценок
- Новинки в любимых жанрах

### Ожидания:
- Точность рекомендаций >70%
- Быстрая работа системы
- Объяснение, почему рекомендован фильм

### Решение системы:
- Гибридная система (LightFM)
- Коллаборативная фильтрация
- Учет жанровых предпочтений

---

## 3. ЭКСПЕРТ (Киноман)

### Характеристики:
- 100+ оцененных фильмов
- Пишет отзывы
- Оценивает детально (1-10)

### Потребности:
- Глубокие рекомендации
- Редкие и нишевые фильмы
- Высокая точность

### Ожидания:
- Рекомендации неочевидных фильмов
- Учет отзывов и текстовых данных
- Интеграция с внешними источниками

### Решение системы:
- Коллаборативная фильтрация (SVD)
- NLP анализ отзывов
- LightGCN для сложных связей

---

## 4. НЕАКТИВНЫЙ ПОЛЬЗОВАТЕЛЬ

### Характеристики:
- Давно не заходил (>30 дней)
- Мало взаимодействий
- Оценки устарели

### Потребности:
- Реактивация через рекомендации
- Напоминание о системе
- Свежие новинки

### Ожидания:
- Email с рекомендациями
- Персонализированная подборка
- Простой возврат в систему

### Решение системы:
- Популярные новинки
- Рекомендации на основе последних оценок
- А/Б тестирование заголовков писем

---

## 5. НОВЫЙ ФИЛЬМ (Проблема холодного старта)

### Характеристики:
- Только добавлен в каталог
- Нет оценок пользователей
- Есть метаданные (жанры, актеры)

### Потребности:
- Получить первые оценки
- Показать целевой аудитории

### Ожидания:
- Рекомендации пользователям с похожими интересами
- 10-20 оценок в первую неделю

### Решение системы:
- Контентная фильтрация на основе жанров
- Рекомендация экспертам
- A/B тестирование постеров
