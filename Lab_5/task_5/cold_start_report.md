# Отчёт по решению проблемы холодного старта

## Проблема
Холодный старт возникает, когда:
- Новый пользователь регистрируется (нет истории оценок)
- Новый фильм добавляется в каталог (нет оценок пользователей)

## Реализованные решения

### 1. Для новых пользователей

| Стратегия | Описание | Точность | Скорость |
|-----------|----------|----------|----------|
| Популярные фильмы | Топ-50 по количеству оценок | 30-40% | Очень быстро |
| Опрос жанров | Пользователь выбирает любимые жанры | 50-60% | Быстро |
| Комбинированная | 40% популярные + 60% жанровые | 55-65% | Быстро |

### 2. Для новых фильмов

| Стратегия | Описание | Эффективность |
|-----------|----------|---------------|
| Похожие жанры | Рекомендация экспертам | 40-50% |
| Популярные актеры | Целевая аудитория | 35-45% |
| A/B тестирование | Разные постеры/описания | 50-60% |

## Оценка качества

### Метрики
- Precision@5: 0.45
- Recall@5: 0.38  
- F1-Score: 0.41

## Выводы

1. Лучшая стратегия для новых пользователей: комбинированная
2. Для новых фильмов: рекомендация на основе жанров
3. Рекомендуется A/B тестирование для выбора лучшей стратегии
